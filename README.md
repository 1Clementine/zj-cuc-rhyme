# Rhyme Signature Submission Package

This package contains the implementation code and known-answer test vectors for
the Rhyme signature algorithm, submitted to the Next-generation Commercial
Cryptographic Algorithms Program (NGCC).

## Algorithm Type

Rhyme is a Fiat-Shamir lattice-based digital signature algorithm.  It uses a
compressed unimodular ("cut-F") construction with widened unimodular matrix
dimension to achieve security against known algebraic attacks on GA-MLWE.

This package contains signature functionality only.  KEM and KEX files are
not part of this submission package.

## Build

See `Implementations/README` for directory-level build instructions.

### Quick start

```bash
# Reference (portable, no special CPU features required)
cd Implementations/Reference_Implementation/Rhyme-128
make clean && make && ./KAT_SIG

# Optimized (requires AES-NI + SSSE3)
cd Implementations/Optimized_Implementation/Rhyme-128
make clean && make && ./KAT_SIG
```

## Test Vectors

Known-answer test vectors are stored in `Test_Vectors/`.  Each file contains
10 deterministic KAT vectors generated by the reference implementation's
`KAT_SIG` executable, using the SM3-based DRNG seeded with fixed nonces.

The KAT output is fully deterministic: re-running the same executable produces
bit-identical output.
